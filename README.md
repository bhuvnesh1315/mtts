# Mathura Tempo Transport Service Website

This is a static, SEO-friendly logistics website for Mathura Tempo Transport Service.

## 🧭 Features
- Responsive HTML/CSS
- SEO optimized
- Local business structure
- Sitemap and robots.txt
- Deployable on GitHub Pages

## 🚀 Deployment
1. Push all files to GitHub
2. Enable GitHub Pages from Settings → Pages
3. Your site will be live at `https://yourusername.github.io/mathura-tempo-transport/`
